# Spec Delta

## REMOVED Requirements

### Requirement: Chrome comum do admin
**Reason**: O backoffice deixa a linguagem de terminal.
**Migration**: Ver `admin-shell`.

### Requirement: Retorno como comando
**Reason**: O retorno passa a ser o menu e o caminho da tela.
**Migration**: Ver `admin-shell`.

### Requirement: Menu como árvore de diretórios
**Reason**: O menu passa a ser em grupos.
**Migration**: Ver `admin-shell`.

### Requirement: Login como tty
**Reason**: O login ganha desenho próprio.
**Migration**: Ver `admin-shell`; erro genérico e limite por IP continuam.

### Requirement: Responsividade do chrome
**Reason**: A garantia passa para a estrutura nova.
**Migration**: Ver `admin-shell`.
