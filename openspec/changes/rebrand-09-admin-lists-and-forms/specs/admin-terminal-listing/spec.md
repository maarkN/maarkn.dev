# Spec Delta

## REMOVED Requirements

### Requirement: Listagem como saída de comando
**Reason**: A lista deixa de imitar saída de terminal.
**Migration**: Ver `admin-listing`.

### Requirement: Paginação como linha de status
**Reason**: A paginação ganha controles próprios; os atalhos continuam.
**Migration**: Ver `admin-listing`.

### Requirement: Estados vazio e de carregamento
**Reason**: Os estados ganham ação seguinte.
**Migration**: Ver `admin-listing`.

### Requirement: Estágio em notação de colchete
**Reason**: O estágio passa a nome e marca de fase.
**Migration**: Ver `admin-listing`.

### Requirement: Board como painéis por estágio
**Reason**: O quadro passa a seis colunas; a contagem real continua.
**Migration**: Ver `admin-listing`.

### Requirement: Agregados com barra decorativa
**Reason**: Os agregados passam para a visão geral.
**Migration**: Ver `admin-overview`.
