# Spec Delta

## REMOVED Requirements

### Requirement: Campos com sotaque de terminal
**Reason**: Os campos deixam a linguagem de terminal.
**Migration**: Ver `admin-forms`.

### Requirement: Erro como saída de erro
**Reason**: O erro passa a orientar a correção.
**Migration**: Ver `admin-forms`.

### Requirement: Ações em colchetes
**Reason**: Os botões passam a nomear a ação.
**Migration**: Ver `admin-forms`.

### Requirement: Retorno como linha de saída
**Reason**: O retorno passa a aviso.
**Migration**: Ver `admin-forms`.

### Requirement: Diálogos com barra de título
**Reason**: As janelas seguem o desenho novo.
**Migration**: Ver `hologram-ui` e `admin-forms`.

### Requirement: Confirmação destrutiva com eco do comando
**Reason**: O eco sai; a digitação do nome continua.
**Migration**: Ver `admin-forms`.
